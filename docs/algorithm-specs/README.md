# 알고리즘 설명서 (제출용)

외부 제출용 「알고리즘 설명서」를 모아 두는 폴더다. 내부 개발 문서인
[`docs/algorithms/`](../algorithms/)와 목적이 다르다 — 저쪽은 **무엇이 사실인가**를 적고,
여기는 **무엇을 어디까지 밖에 내보낼 것인가**를 적는다.

| 파일 | 내용 | 제출 |
|---|---|---|
| [00-작성규칙.md](./00-작성규칙.md) | 공통 작성규칙 5가지, 비공개 판정 기준, 서식 구조, 제출 전 체크리스트 | ✕ |
| [00-변환가이드.md](./00-변환가이드.md) | 내부 문서 → 설명서 매핑표, **비공개 처리 대응표**, 용어 순화 사전 | ✕ **내부 전용** |
| [알고리즘1_설명서.md](./알고리즘1_설명서.md) | 알고리즘 #1 (코스피 전체) 설명서 | ○ |
| [알고리즘1_추가필요자료.md](./알고리즘1_추가필요자료.md) | 위 문서 작성 후 남은 빈칸·확인사항·판단 필요사항 | ✕ |

## 작업 순서

1. [00-작성규칙.md](./00-작성규칙.md) 를 읽고 그 알고리즘에 걸린 **제약조건**을 확정한다
2. [00-변환가이드.md](./00-변환가이드.md) 의 매핑표대로 `docs/algorithms/` 원천 문서에서 재료를 뽑는다
3. **비공개 처리 대응표**를 적용해 감출 표현을 바꾼다
4. 설명서를 쓴다 — 맨 위에 제약조건 블록, 본문은 서식 구조 그대로
5. 빈칸·확인사항을 `*_추가필요자료.md`로 분리해 보고한다
6. 제출 전 체크리스트로 확인한다

## 반드시 지킬 것 (요약)

- 맨 위에 **제약조건**을 본문과 구분해 기입
- 작성 후 **추가로 필요한 정보·자료를 정리해 보고**
- **알고리즘이 직접 드러나는 내용은 쓰지 않음** — 기법의 범주와 목적까지만
- **어려운 말을 쓰지 않음** — 금융은 알지만 알고리즘 개발은 안 해본 독자 기준
- **백테스팅·실험 결과를 쓰지 않음** — 절차와 검증 체계는 쓰되 그 결과 수치는 쓰지 않음
