# 알고리즘 설명서 작성규칙 (공통)

> 제출용 「알고리즘 설명서」를 쓸 때 **모든 알고리즘에 공통으로 적용**되는 규칙이다.
> 서식 원본은 `reference/docs/알고리즘설명서_템플릿.md` (gitignore 대상이라 이 리포에는 없다).
> 알고리즘별 제약조건은 각 설명서 맨 위에 따로 적는다.

---

## 1. 사용자가 지정한 규칙 5가지 (반드시 지킬 것)

| # | 규칙 | 실무적 의미 |
|---|---|---|
| R1 | **맨 위에 제약조건을 기입하고 본문과 구분한다** | 문서 첫머리에 `제약조건` 블록을 두고 인용부호(`>`)나 구분선으로 본문과 시각적으로 분리한다. 유니버스·서술수준·미기재 항목 등 그 문서에 걸린 조건을 전부 적는다 |
| R2 | **작성 후 추가로 필요한 정보·자료를 정리해 보고한다** | 설명서 본문에 섞지 않고 `*_추가필요자료.md`로 분리한다. 제출 전에 채워야 할 빈칸(업체명·BM 등)과, 판단이 필요한 항목을 구분해서 적는다 |
| R3 | **알고리즘이 직접적으로 드러나는 내용은 쓰지 않는다** | 핵심 기술이 외부로 드러나면 안 된다는 설정. **기법의 "범주와 목적"까지만** 쓰고 팩터 정의식·임계치·룩백기간·순위 규칙은 쓰지 않는다. 판정 기준은 아래 2절 |
| R4 | **어려운 말을 쓰지 않는다** | 독자 기준은 **"금융은 잘 알지만 알고리즘 개발은 해본 적 없는 사람"**. 금융 용어(밸류에이션·업종·리밸런싱·변동성)는 그대로 써도 되고, 개발·통계 용어(z-score, HHI, IC, Newey-West, 룩백, 오버레이)는 풀어 쓰거나 뺀다 |
| R5 | **백테스팅 결과·실험 결과를 쓰지 않는다** | CAGR·샤프·MDD·변동성·회전율·승률, "몇 개 실험 중 몇 개 채택" 같은 수치가 전부 해당. **성과를 만들어내는 절차·체계는 써도 된다** — 쓰면 안 되는 건 그 절차가 낸 숫자다 |

R5는 특히 헷갈리기 쉬우니 예를 남긴다.

- ❌ "백테스트 기간 연평균 38.3%, 최대낙폭 −24.9%"
- ❌ "18건의 실험 중 6건을 채택했다"
- ⭕ "리밸런싱 시마다 목표 포트폴리오의 예상 변동성과 최대낙폭을 사전 점검한다"
- ⭕ "복수의 유니버스에서 같은 방향의 결과가 나오지 않으면 채택하지 않는다"

## 2. R3 판정 기준 — 어디까지 쓰고 어디부터 감추나

**"경쟁사가 이 문장만 보고 같은 전략을 재현할 수 있는가"** 로 판정한다.

| 구분 | 처리 | 예 |
|---|---|---|
| 기법의 **범주** | 쓴다 | "재무지표 기반 선별", "가격 흐름 기반 순위화", "규모 연동 비중배분" |
| 기법의 **목적·효과** | 쓴다 | "업종 쏠림 방지", "급락 종목의 손실 확대 차단" |
| **공시 성격의 한도** | 쓴다 | 동일종목 비중 상한, 업종 비중 상한, 리밸런싱 주기 |
| **어떤 지표**를 쓰는지 | 감춘다 | EBITDA PEG → "수익성 대비 밸류에이션 지표" |
| **임계치·기간·순위 규칙** | 감춘다 | 하위 50%, 12개월, 상위 20종목, −10%, 200일 |
| **판정 로직의 순서·조합** | 요약만 | "선별 → 순위화 → 비중배분 → 위험관리" 수준까지 |

한도(상한 %)와 신호 임계치를 헷갈리지 말 것. **한도는 투자자에게 공시하는 약속**이라 적어야 하고,
**임계치는 알파의 출처**라 적으면 안 된다.

## 3. 서식 구조 (템플릿 고정)

바꾸지 말고 그대로 따른다. 표의 열 구성도 유지한다.

| 장 | 절 | 내용 |
|---|---|---|
| 1. 알고리즘 일반현황 | (1) 알고리즘 개요 | 알고리즘명·업체명·투자목적·투자방침·투자전략·벤치마크 6행 표 |
| | (2) 수행내역 및 적용기술 | 전체 개요 → 주요 단계별 개요(단계마다 `기술명:` 표기) |
| | (3) 주요 특장점 | 1) 솔루션 측면 2) 수행 분야별. **심사 참고 태그를 빠짐없이 단다** |
| 2. 포트폴리오 운용방식 | (1) 편입자산 종류 및 특징 | 자산군·자산종류·포함종목수·특징 |
| | (2) 편입자산 고려사항 | 편입/편출 기준, 제외 대상 |
| | (3) 투자한도 | 동일종목·산업분류별·ETF |
| 3. 주요위험 및 위험관리 | (1) 주요 투자위험 | 위험명 + 내용 표 |
| | (2) 위험관리 방법 | 목록 |
| 4. 리밸런싱 | (1) 기준 | 정기/수시 |
| | (2) 절차 | 정기·수시 각각 순서 표 |
| | (3) 안정성·수익성 평가 | **과정만** 서술 (R5) |
| | (4) 투자목적·방침 반영 | 한도 초과 시 조정 원칙 |

### 심사 세부 항목 (정성평가 근거) — 2026-08-13 수령

1-(3)에 아래 태그가 **전부** 한 번 이상 나와야 한다. 빠지면 그 항목은 평가받지 못한다.
"설명" 열은 심사 측이 제시한 원문이므로 **이 문장이 묻는 것에 정확히 답하도록** 서술한다.

| 태그 | 심사 측 설명 (원문) | 우리 재료 |
|---|---|---|
| `[핵심 로직 독창성]` | 알고리즘의 근간이 되는 로직이 기존 전략과 어떻게 다른지 | 재무 선별과 주가 흐름을 **순차 결합**(종합 점수 합산 아님), 수익 로직과 위험 로직의 **분리** |
| `[시장국면별 대응력]` | 변동성 확대·하락 국면 등에서의 대응 규칙이 **사전 정의**되어 있는지 | 개별 종목 손실 제한 + 시장 국면 판단의 이중 장치, 회수 자금은 현금 보유 |
| `[유니버스 선정 전문성]` | 투자 유니버스 정제 기준(상장기간, 관리종목 제외 등)의 합리성 | 관리종목·거래정지·SPAC·우선주 제외, 종목코드 기반 우선주 판별, 시점별 종목군 재구성 |
| `[과최적화 방지 체계]` | **표본 외(Out-of-Sample) 검증, 롤링 추정** 등 오버피팅 방지 장치 | `methodology.md` §1 — 다만 **표본 외 검증은 아직 미실시**(E1). 아래 주의 참조 |
| `[리스크 관리]` | 종목·업종 한도, 손실 확대 구간 대응 규칙의 **사전 정의 여부** | 동일종목 25% / 업종 50% / 동일업종 2종목, 손실 제한·국면 대응 규칙 |
| `[슬리피지 관리]` | **유동성 대비 과도한 편입 규모를 통제**하는 장치 | 규모 연동 비중배분, 비중 상한, 미미 비중 제외, 월 1회 리밸런싱. **거래대금 대비 통제는 미구현**(E2·E3) |
| `[R&D 인력 및 팀 역량]` | 퀀트 운용·개발 인력의 **경력과 팀 구성** | **알고리즘 설명서로는 답할 수 없다** — 회사·조직 자료가 필요하다 |
| `[알고리즘 고도화 로드맵]` | 향후 팩터 확장·모델 정교화 등 개선 계획 | 로드맵 3단계 |

**주의할 항목 셋.**

- **`[과최적화 방지 체계]`가 콕 집어 "표본 외 검증"과 "롤링 추정"을 묻는다.** 우리는 검증
  전용 구간을 봉인해 뒀지만 **아직 한 번도 열지 않았고, 롤링 재추정도 하지 않는다**(설정값
  고정). 있는 것(봉인·사전 등록·복수 종목군 검증·기각 기록)을 쓰고 **없는 것을 있다고 쓰지
  않는다.** 표본 외 검증은 로드맵에 계획으로 적는다.
- **`[슬리피지 관리]`도 "유동성 대비 편입 규모 통제"를 콕 집는다.** 우리 장치는 전부
  **간접적**이다(규모 연동 가중, 비중 상한). 거래대금 대비 주문 규모를 직접 재거나 제한하는
  장치는 없으므로, 간접 장치를 쓰되 직접 통제는 다음 단계 과제로 명시한다.
- **`[R&D 인력 및 팀 역량]`은 알고리즘 설명서의 범위 밖이다.** 별도 회사·조직 자료로
  제출하는지, 설명서 1-(3)에 한 문단을 넣어야 하는지 확인이 필요하다.

## 4. 서식이 전제하는 제약 (템플릿 안내문에서)

- 투자대상은 **국내 상장 주식(KOSPI/KOSDAQ) 및 국내 상장 ETF**로 한정. 해외자산·펀드 불가
- 포함종목수는 정확할 필요 없음 — 유니버스 규모 파악 용도
- **별도 제출하는 백테스팅 자료와 자산종류·시장구분이 일치해야 함**
  (설명서에 성과 수치는 안 쓰지만, 자산 구성은 백테스트와 어긋나면 안 된다)
- 벤치마크는 사전 승인 대상 — 최종 확정은 협의
- 동일종목 한도에는 "시가총액이 시장 전체의 10%를 초과하는 종목은 예외" 조항이 있음
- ETF는 개별종목 투자한도 적용 대상에서 제외
- 매매 제한 종목이 리밸런싱 결과에 포함되면 대체 종목으로 교체 요청이 올 수 있음

## 5. 제출 전 체크리스트

- [ ] 맨 위 제약조건 블록이 본문과 구분돼 있는가 (R1)
- [ ] 성과 수치가 한 개도 없는가 — 표·각주·예시 포함 (R5)
- [ ] 팩터명·임계치·기간·종목수 순위 규칙이 노출되지 않았는가 (R3)
- [ ] 개발·통계 용어가 남아 있지 않은가 (R4)
- [ ] 심사 참고 태그 7종이 모두 있는가
- [ ] 자산 구성이 함께 제출할 백테스팅 자료와 일치하는가
- [ ] 채워야 할 빈칸이 `⟨확인 필요⟩`로 표시돼 있고, 추가필요자료 문서에 목록이 있는가 (R2)
- [ ] 실거래가 아닌 것을 성과처럼 읽히게 쓴 문장이 없는가
