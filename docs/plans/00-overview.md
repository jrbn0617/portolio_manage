# 포트폴리오 관리 프로그램 — 전체 개요

## 목적
개인용 포트폴리오 관리 웹 애플리케이션. 크게 세 가지 기능으로 구성되며 아래 순서로 단계적으로 개발한다.

1. [데이터 관리](./01-data-management.md)
2. [퀀트 전략 백테스팅](./02-backtesting.md)
3. [포트폴리오 관리](./03-portfolio-management.md)

각 단계는 별도의 계획 문서로 관리한다. 아직 착수하지 않은 단계는 개요 수준으로만 작성되어 있으며, 해당 단계에 들어갈 때 상세 계획으로 다시 다듬는다.

## 기술 스택
- **백엔드**: Python + FastAPI
  - 2단계 퀀트 백테스팅에서 수치 연산·데이터 분석 비중이 크기 때문에 pandas/numpy 생태계를 그대로 쓸 수 있는 Python을 선택
- **데이터베이스**: PostgreSQL
- **프론트엔드**: React (Vite)
- **인증**: 없음 — 개인용 로컬 단일 사용자 기준으로 설계 (추후 다중 사용자 필요 시 별도 검토)

## 저장소 구조
```
portolio_manage/
├── backend/         # FastAPI 앱
├── frontend/        # React (Vite) 앱
└── docs/plans/       # 단계별 계획 문서
```

## 진행 방식
- 단계는 순차적으로 진행한다 (데이터 관리 → 백테스팅 → 포트폴리오 관리).
- 이전 단계에서 쌓은 데이터/구조를 다음 단계가 재사용하는 것을 전제로 설계한다.
- 요구사항은 진행하면서 구체화될 수 있으므로, 각 계획 문서는 해당 단계 착수 시점 기준으로 최신화한다.
