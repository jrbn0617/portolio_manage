# 알고리즘 #1 — EBITDA PEG 스크리닝 + 모멘텀 (섹터캡·손절·레짐필터)

> 상태: **확정, 개발 종료.** 실험 1~12까지 진행 후 아래 파라미터로 최종 확정.
> 상세 실험 과정(각 실험의 가설·구현·수치)은 [04-screening-experiments.md](./04-screening-experiments.md) 참고.
> **주의: 백테스트 결과이며 실거래/실자금 운용 결과가 아니다.**

## 1. 개요
- **대상 유니버스**: 코스닥150 / 코스피200 / 코스피전체 / 코스닥전체 (4개 독립 운용, 유니버스별 파라미터 동일)
- **한줄 요약**: EBITDA PEG 팩터로 저평가 성장주를 1차 스크리닝한 뒤, 모멘텀 상위 종목을 유동시총가중으로 담는 월간 리밸런싱 전략. 개별종목 월중 손절과 시장 레짐필터로 하방을 방어.
- **리밸런싱 주기**: 매월말
- **백테스트 기간**: 2020-01-01 ~ 2026-07-31 (약 6.6년, 79회 리밸런싱)

## 2. 전략 로직 (파이프라인)
1. **유니버스**: 반기 스냅샷 기준 지수 편입종목(코스닥150 등)
2. **스크리닝**: EBITDA PEG(TTM lag 90일) 섹터별 하위 50%만 통과 — 저평가 성장주 1차 필터
3. **랭킹**: 스크리닝 통과 종목을 12개월(최근 1개월 제외) 가격 모멘텀 상위순 정렬
4. **종목 선정**: 상위 20종목, **섹터당 최대 2종목** 제한(카운트 기반 분산)
5. **가중치**: 유동주식시가총액 비례(유동시총가중), 종목당 최대 30% 상한
6. **리스크 오버레이 A — 월중 개별종목 손절**: 직전 리밸런싱 종가 대비 **-10%** 하락 시, 다음 거래일 시가로 매도했다고 가정하고 잔여 기간 가치를 동결(현금 보유, 재배분 없음)
7. **리스크 오버레이 B — 시장 레짐필터**: 벤치마크 지수 200일 이동평균 기준으로 약세 판정 시 포트폴리오 전체 비중을 100%→50%로 축소(나머지는 현금)

## 3. 확정 파라미터

| 파라미터 | 값 |
|---|---|
| top_n | 20 |
| 섹터당 최대 종목수 | 2 |
| 가중치 방식 | 유동시총가중, 종목당 최대 30% |
| 스크리닝 팩터 | EBITDA PEG, 섹터별 하위 50%, TTM lag 90일 |
| 랭킹 | 순수 모멘텀(12개월, 최근 1개월 제외) |
| 손절 기준 | -10%, 익일시가체결 |
| 레짐필터 | 지수 200일이평, 약세시 비중 50% |
| 리밸런싱 주기 | 매월말 |

재현: `backend/scripts/export_stoploss_regime_combo_backtest_excel.py --stop-loss-pct 0.10`

| 코스닥150 | 24.8% | 27.8% | -31.9% | 0.96 |
| 코스피200 | 32.3% | 24.7% | -33.2% | 1.29 |
| 코스피전체 | 39.5% | 25.1% | -26.2% | 1.49 |
| 코스닥전체 | 22.9% | 28.4% | -36.3% | 0.89 |

## 5. 실험 히스토리 요약 (12건, 상세는 04-screening-experiments.md)

| # | 아이디어 | 결과 |
|---|---|---|
| 1 | 통합 스코어(PEG+모멘텀 z-score) | 기각 — 전 지표 악화 |
| 2 | PEG>0 조건 완화 | 기각 — 샤프 악화 |
| 3 | 변동성조정 모멘텀 | 기각 — 코스닥150만 개선, 범용성 없음 |
| 4 | 3/6/12개월 모멘텀 블렌딩 | 기각 — 유니버스별 결과 상반 |
| 5 | 장기이평 추세필터 | 기각 — 전부 악화 |
| 6 | 월중 손절(-15%→-10%, 익일시가체결) | **채택** — 4개 전부 개선 |
| 7 | 시장 레짐필터(200일선, 약세시 50%) | **채택** — 4개 전부 개선 |
| 8 | 리밸런싱 밴드(매수15/매도30) | 기각 — 회전율↓ 하지만 성과 뚜렷이 악화 |
| 9 | 실험6+7 조합 | **채택** — 단독보다 시너지, 손절선/top_n 재튜닝(-10%, top20) |
| 10 | 섹터캡 제거 + 가중치 4종(동일가중/업종·섹터·산업 그룹50%캡) | 기각 — 동일가중 뚜렷 악화, 그룹캡은 MDD 전부 악화 |
| 11 | 섹터캡(2종목) 유지 + 동일섹터 합산50%캡 병행 | 기각(no-op) — 사실상 무변화 |
| 12 | 섹터캡(2종목) 유지 + 업종/산업 합산50%캡 병행 | 기각(no-op) — 분류체계 무관하게 무변화 |

**핵심 인사이트**: 리스크 관리는 스크리닝/랭킹/가중치 로직이 아니라 별도 오버레이(개별종목 손절 + 포트폴리오 레짐필터)로 넣는 게 효과적이었다. 종목 분산은 카운트 기반 제한(섹터당 N종목)이 합산비중 기반 제한(그룹캡 %)보다 실질적으로 더 강하게 작동했다.

## 6. 한계 및 주의사항
- **백테스트이며 실거래 아님.** 거래비용·슬리피지·세금 미반영.
- 벤치마크 지수 데이터가 2019-12-02부터 시작해 200일 레짐필터가 2020-10경부터 계산 가능 — **2020년 3월 코로나 폭락은 레짐필터가 잡지 못함.**
- 손절의 종가/익일시가 체결 가정, 오버나이트 갭 비율은 배당조정이 아닌 분할조정 가격 기준 근사치.
- EBITDA PEG는 TTM 실적 기준(lag 90일)이며 컨센서스 기반이 아님.
