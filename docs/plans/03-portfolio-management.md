# 3단계 — 포트폴리오 관리

[← 전체 개요](./00-overview.md)

> 개요 수준 문서. [2단계 퀀트 전략 백테스팅](./02-backtesting.md) 완료 후 착수 시점에 상세 계획으로 다시 작성한다.

## 목표
실제 보유 중인 포트폴리오의 구성/비중을 관리하고, 리밸런싱과 성과 추적을 지원한다.

## 착수 시 검토할 항목
- **보유내역 입력 방식**: 1단계 업로드 방식 재사용 여부, 수동 입력 화면 필요 여부
- **비중 계산**: 종목별/자산군별 비중 산출 및 시각화
- **리밸런싱**: 목표 비중 대비 괴리 계산, 리밸런싱 제안 로직
- **성과 추적**: 기간 수익률, 벤치마크(기초지수) 대비 성과 비교 — 1단계에서 관리하는 지수 데이터 활용
- **2단계와의 연계**: 백테스팅한 전략을 실제 포트폴리오에 반영하는 흐름 필요 여부
