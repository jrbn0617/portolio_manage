# 2단계 — 퀀트 전략 백테스팅

[← 전체 개요](./00-overview.md)

> 개요 수준 문서. [1단계 데이터 관리](./01-data-management.md) 완료 후 착수 시점에 상세 계획으로 다시 작성한다.

## 목표
1단계에서 적재한 가격/배당/거시지표 데이터를 활용해 사용자가 정의한 퀀트 전략을 백테스팅한다.

## 착수 시 검토할 항목
- **전략 정의 방식**: 코드로 직접 작성 vs 파라미터 기반 룰(예: 이동평균 교차, 팩터 스코어링 등) 조합
- **백테스팅 엔진**: 자체 구현 vs 기존 라이브러리(vectorbt, backtrader 등) 활용
- **성과 지표**: 누적수익률, MDD(최대낙폭), 샤프비율, 승률 등
- **결과 시각화**: 수익률 곡선, 낙폭 그래프, 지표 요약 테이블
- **데이터 의존성**: 1단계 스키마(`prices`, `dividends`, `macro_indicators`)를 그대로 활용할지, 백테스팅 전용 뷰/캐시가 필요할지
