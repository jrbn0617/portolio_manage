## 기록 방식

각 실험 완료 시 이 표의 "상태"를 완료로 바꾸고 "결과 요약"에 베이스라인 대비 변동(연변동성/MDD/샤프)을
1줄로 남긴다. 상세 수치·엑셀 파일은 각 실험 브랜치의 커밋에 포함.

### 실험 9: 월중손절 + 시장레짐필터 조합

계획된 8개 실험 중 유일하게 4개 유니버스 전부에서 개선된 게 실험6(월중 개별종목 손절, -15%
익일시가체결)과 실험7(지수 이평선 기준 포트폴리오 전체 노출비중 조절, 약세시 50%)이었다.
둘 다 스크리닝·랭킹은 안 건드리고 리스크관리 오버레이만 얹는 방식이라는 공통점이 있어서,
동시에 적용했을 때 시너지가 있는지 확인.

구현: 두 훅(`stop_loss_pct`/`stop_loss_execution`, `exposure_fn`)을 한 브랜치에 합쳐
`run_momentum_backtest`에 동시 전달(스크리닝/랭킹/가중치는 베이스라인과 동일, 손절은
실험6에서 더 나았던 익일시가체결 방식 사용). 실험7에서 발견한 캐쉬비중 미반영 버그 수정도
동일하게 반영. 스모크테스트+NAV 이상치 검사로 회귀 없음 확인.
