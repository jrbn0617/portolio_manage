## 1. 개요

**세 개의 on/off 스위치로 8가지 국면을 만들고, 국면마다 정해진 자산군 비중표를 꺼내 쓰는
전술적 자산배분이다.** 최적화도 스코어링도 없다 — 스위치가 켜지면 그 자산을 늘리고 꺼지면
줄인다. 비중은 사람이 미리 정해 표에 박아 둔 값이다.

| | |
|---|---|
| 자산군 | 주식 · 금 · 채권 · 현금 |
| 스위치 | 주식(마진부채), 금(금 vs 금리), 채권(채권 모멘텀) — 각각 0/1 |
| 신호 주기 | 월간 |
| 리밸런싱 | **분기말** (`freq='QE'`) — 월간 신호 중 분기말 값만 쓴다 |
| 위험도 | 3단계 (`risk=0/1/2` → MP1/MP2/MP3) |
| 벤치마크 | MSCI ACWI NTR 60 / Bloomberg Global-Agg 40 |
| 거래비용 | 원본 백테스트에서 0.1% |
| 검증 구간 | 원본 산출물 기준 1999-12-31 또는 2007-12-31 ~ 2026-06-30 |

## 2. 전략 로직

```
경제지표 3종 ─→ 스위치 3개 ─→ 8가지 조합 ─→ 자산군 비중표 ─→ 개별 지수 비중 ─→ 위험도 축소
 (월간)          (0/1)         '000'~'111'    (주식/금/채권/현금)   (7:2:1 등)      (현금으로 흡수)
```

### 2.1 주식 스위치 — 마진부채

```
margin_debt × (M2 / M2.shift(12))        ← M2 전년동월비를 곱한다
    → 12개월 롤링 z-score
    → 히스테리시스(진입 −0.5, 이탈 −1.5)
```

마진부채가 최근 12개월 평균 대비 **−1.5σ 아래로 떨어지면 위험을 줄이고**, −0.5σ 위로
돌아오면 되돌린다. 밴드가 1.0σ로 넓어서 한 번 꺼지면 쉽게 켜지지 않는다.

**나누지 않고 곱하는 것이 의도다 — 유동성 가중 신용 팽창지수다.** 통화량으로 정규화하려면
나누는 게 보통이라 버그로 보이기 쉬운데 그렇지 않다. 레버리지를 지탱할 기초 체력이 신용과
함께 커지고 있는지를 묻는 구조다. 신용잔고는 높은데 M2 증가율이 둔화되거나 마이너스로
가면 지표가 급격히 꺾이고, 그건 **유동성이라는 지지대가 사라진 채 빚만 위태롭게 쌓인
상태**를 뜻한다 — 이 전략에서 가장 강한 매도 신호다.

채권 스위치는 반대로 M2 증가율로 나눈다(§2.3). 방향이 다른 것은 묻는 질문이 다르기
때문이지 실수가 아니다.

### 2.2 금 스위치 — 금 vs 금리

```
모멘텀(x) = x/x.shift(12) + x/x.shift(6) + x/x.shift(3)     ← 3·6·12개월 합

합성 채권 = ((DGS10 × 0.01 + 1) ** (1/12)).cumprod()

금 모멘텀 > 합성 채권 모멘텀 인 달의 비율이
    최근 12개월 중 70% 초과  →  ON
```

**합성 채권은 채권 총수익이 아니다.** 10년물 금리로 월복리 누적한 것이라 금리 변동에 따른
가격 손익(듀레이션 효과)이 없다 — 사실상 "10년물 금리로 굴린 예금"이다. 금이 그 수익률을
꾸준히 이기는 국면인가를 묻는 구조다.

히스테리시스가 없는 대신 **12개월 중 70% 조건**이 같은 역할(잦은 전환 억제)을 한다.

### 2.3 채권 스위치 — 채권 모멘텀

```
모멘텀(x) = x/x.shift(12) + x/x.shift(6)     ← 6·12개월 합 (3개월 없음)
    ÷ (M2 / M2.shift(12))                    ← M2 전년동월비로 나눈다
    → 12개월 롤링 z-score
    → 히스테리시스(진입 −0.8, 이탈 −1.0)
```

밴드가 0.2σ로 좁아 주식 스위치보다 훨씬 자주 뒤집힌다.

### 2.4 발표 시차

```python
df['m2ns'] = df['m2ns'].shift(1)
df['margin_debt'] = df['margin_debt'].shift(1)
```

M2와 마진부채만 한 달 민다. 둘 다 익월에 발표되므로 **미래 참조를 막는 처리다.**
DGS10은 밀지 않는다 — 월평균이라 월말에 이미 확정돼 있다.

## 3. 파라미터

### 3.1 국면별 자산군 비중 (`weight_sheet`)

키는 **주식·금·채권** 순서의 3자리 문자열이다.

| 스위치 | 주식 | 금 | 채권 | 현금 |
|---|---|---|---|---|
| `000` 전부 off | 0.60 | 0.05 | 0.05 | 0.30 |
| `010` 금 | 0.60 | 0.20 | 0.05 | 0.15 |
| `001` 채권 | 0.60 | 0.05 | 0.20 | 0.15 |
| `011` 금+채권 | 0.60 | 0.20 | 0.20 | 0.00 |
| `100` 주식 | 0.76 | 0.10 | 0.10 | 0.04 |
| `110` 주식+금 | 0.76 | 0.15 | 0.025 | 0.065 |
| `101` 주식+채권 | 0.76 | 0.025 | 0.175 | 0.04 |
| `111` 전부 on | 0.76 | 0.095 | 0.095 | 0.05 |

**스위치는 자산을 껐다 켜는 게 아니라 가감한다.** 전부 off인 `000`에서도 주식이 60%다.
주식은 60% ↔ 76% 사이에서만 움직이고, 실제로 크게 흔들리는 건 금·채권·현금이다.

주식이 켜지면(`1xx`) 금과 채권의 합이 0.25 → 0.19로 줄고 현금도 얇아진다.

### 3.2 자산군 → 개별 지수

| 자산군 | 분해 |
|---|---|
| 주식 | 미국 : EAFE : EM = **7 : 2 : 1** (위험도 무관) |
| 채권 | 30년 : 10년 = risk0 **8:2** · risk1 **65:35** · risk2 **5:5** |
| 금 | 전액 금 |
| 현금 | `1 − 나머지 합` |

### 3.3 위험도

```python
if risk == 1: port_df *= 0.8
elif risk == 2: port_df *= 0.65
```

위험자산 전체를 축소하고 **줄어든 만큼 현금이 받는다.** 채권 만기 구성도 함께 짧아진다
(위 표) — 위험도가 높을수록 듀레이션도 줄인다.

백테스트는 이식하지 않았으므로 성과 수치는 없다. 대신 **원본이 만든 목표비중과 직접

| 원본 | 0.760 | 0.025 | 0.175 | 0.040 | `101` |

```
금 스위치가 갈리는 달   4 / 415 개월   (2008-11, 2009-08, 2017-02, 2019-09)
그중 분기말에 걸린 것    1 회           (2019-09-30)
```

70% 임계값이 12개월 중 8.4개월이라 한 달 차이로 판정이 뒤집힌다. 나머지 세 번은 분기말이
아니어서 비중에 반영되지 않았다.

**이 차이는 감수하기로 했다** (사용자 결정, 2026-08-20). `GOLDLNPM`은 블룸버그
엔타이틀먼트에 없어 받을 수 없고, `XAU`는 매일 갱신되며 다른 미국물과 스냅 시각이 맞는다.

## 6. 한계 및 주의사항

### 6.1 코드에서 확인한 것 (실측)

**① `margin_debt *= m2_yoy` 가 호출자의 DataFrame을 바꾼다.**
pandas 2.2.3에서 확인했다 — `df['margin_debt']`를 넘기면 원본 열이 변형된다. 지금은
뒤에 오는 두 신호가 `margin_debt`를 쓰지 않아 결과에 영향이 없지만, 신호를 하나
추가하거나 순서를 바꾸면 조용히 틀어진다.

**② `x[-1]` 이 곧 깨진다.**
`rolling(12).apply(lambda x: (x[-1] - x.mean()) / ...)` 의 `x[-1]`은 pandas 2.2.3에서
`FutureWarning`이 뜬다 — "Series.__getitem__ treating keys as positions is deprecated".
`x.iloc[-1]`로 바꿔야 한다.

**③ `read_underlying_price(start, end)` 가 `start`를 무시한다.**
항상 `'19000101'`부터 읽는다. 지금은 뒤에서 `df[start:end]`로 자르므로 결과는 맞다.

**④ `MSCIACWINTR`이 유니버스에 있는데 비중이 0이다.**
`UNIVERSE['gold']`에 `MSCIACWINTR`과 `US10Y`가 들어 있어 `port_df` 열로는 만들어지지만
`asset_allocation`이 값을 넣지 않아 계속 0이다. ACWI는 벤치마크(60/40)에만 쓰인다.

### 6.2 설계상 유의점

- **신호는 월간, 리밸런싱은 분기말.** 분기 중간에 스위치가 뒤집혀도 반영되지 않는다.
  `sig_str_sr.loc[x]`가 분기말 인덱스와 정확히 맞아야 하므로 신호 인덱스가 월말이어야 한다.
- **히스테리시스 초기 상태가 0이다.** 계열 시작 시점에 모든 스위치가 off에서 출발한다.
- **금 스위치의 합성 채권에 듀레이션이 없다.** 금리가 급등한 구간에서 실제 채권은 손실인데
  이 합성 계열은 계속 오른다 — 금 스위치가 그만큼 늦게 켜진다.
- **z-score 창이 12개월로 짧다.** 표본 12개로 표준편차를 재므로 값이 불안정하다.
- **거래비용 0.1%는 원본 백테스트의 가정이다.** 지수를 직접 살 수 없으므로 실제로는
  ETF·펀드 보수와 추적오차가 더 붙는다.

## 7. 이식 결과

`backend/analysis/allocation/cycle_switch.py`. 원본과 달라진 것은 셋뿐이고 **전부 결과를
바꾸지 않는다** — §4의 대조가 그것을 보여준다.

1. **데이터 원천** — 소스 DB `underlying_index` → 우리 `prices` + `macro_indicators`
2. **`x[-1]` → `x.iloc[-1]`** — pandas 2.2.3 에서 FutureWarning 이 뜬다. 위치 인덱싱이라 값은 같다
3. **마진부채를 복사해서 쓴다** — 원본의 in-place 변형(§6.1 ①)을 끊었다

```bash
cd backend
venv/bin/python analysis/allocation/cycle_switch.py            # 최근 스위치와 목표비중
venv/bin/python analysis/allocation/cycle_switch.py --risk 1
venv/bin/python analysis/allocation/cycle_switch.py --from 2020-01-01 --history
```

유효 구간은 **1998-01-31 이후**다. 마진부채가 1997-01 부터라 전년동월비 12개월과 z-score
12개월을 먹고 나면 그때부터 세 신호가 모두 산다.

### 아직 안 한 것

- **백테스트** — 원본은 별도 `backtester` 패키지의 `run_backtest`를 쓰고 이 리포에는 없다.
  성과 수치를 말하려면 이걸 먼저 정해야 한다(직접 구현할지, 그 패키지를 가져올지).
- **벤치마크** — 원본의 ACWI 60 / Global-Agg 40. 데이터(`NDUEACWF`, `LEGATRUU`)는 있다.
- **거래비용 가정** — 원본 백테스트는 0.1%. 지수를 직접 살 수 없으므로 실제 집행 수단
  (ETF·펀드)을 정한 뒤 다시 잡아야 한다.
